🌐 Erişim Modu
Lyra'ya nasıl erişeceğini seç. Daha sonra ayarlar menüsünden değiştirebilirsin.
🌍
Public — Domain ile (önerilen)
Kendi domain'inle erişirsin (örn. lyra.example.com). Caddy otomatik HTTPS sertifikası alır.
🏠
LAN — Yerel ağ
Ağındaki tüm cihazlardan erişebilir. Ev/ofis sunucusu için ideal.
☁️
Cloudflare Tunnel — otomatik (API token ile)
Sunucunun public IP'si yoksa (NAT/CGNAT) veya CF koruması istiyorsan. Bir API token + domain verirsin; tunnel, yönlendirme ve DNS kayıtlarını Lyra kendisi oluşturur. Cloudflare panelinde elle iş yok.
🔒
Localhost — Sadece bu makineden
SSH tunnel ile uzaktan erişirsin. En güvenli, ek kurulum gerektirmez.
⚙️
Cloudflare Tunnel — connector token (ileri seçenek)
Tunnel'ı Cloudflare dashboard'da kendin oluşturup public hostname'leri kendin eklemek istiyorsan. Lyra sadece connector token'ı alıp cloudflared'i kurar. Çoğu kullanıcı için yukarıdaki otomatik mod daha kolaydır.
🔧
Manuel — Kendi reverse proxy'm var
Kendi nginx/traefik/HAProxy'ni kullanacaksan. Lyra 127.0.0.1'e bind olur, gerisi sende.
