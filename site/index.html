Sunucun, senin panelin

Lyra kendi sunucunda çalışan bir geliştirici ortamı paneli. Projelerini klonla, tarayıcıdaki IDE'de aç, dev server portlarını izle, git işlerini yürüt, ortam değişkenlerini düzenle, logları canlı takip et — hepsi tek yerden.

Kurulum rehberi Kaynak kodu 
$ git clone https://github.com/eminerolll/andromeda-lyra.git lyra && cd lyra
$ sudo ./install.sh

Ne yapıyor

Yedi sekme, tek panel. Docker ve Tunnel opsiyonel.

Projeler

Klonla, oluştur, aç

GitHub deposu klonla ya da şablondan başla (Node, Python, React, Next). Sabitle, yeniden adlandır, code-server'da aç.

Portlar

Çalışan dev server'lar

Hangi port hangi projeye ait, ne kadar RAM yiyor, ne zamandır ayakta — canlı liste. Takılan süreci panelden durdur.

Git

Tarayıcıdan git

Status, commit geçmişi, diff. Pull, push, commit, checkout, stash — çakışma tespiti Türkçe ve İngilizce git çıktısını birlikte anlıyor.

Ortam

.env yönetimi

Proje .env dosyalarını düzenle (monorepo destekli), global değişkenleri tek yerde tut. Hassas değerler maskeli gelir.

Loglar

Canlı journalctl

Kayıtlı her systemd servisi için canlı log akışı; filtrele, ara, duraklat.

Docker · Tunnel

Opsiyonel eklentiler

Container'lar, stats, compose up/down. Cloudflare Tunnel ingress ve DNS kayıtlarını panelden yönet.

Hiçbir port açmadan yayında

  • Kurulumda Cloudflare API token'ı verirsen tunnel, DNS ve TLS otomatik kurulur
  • NAT, CGNAT ve bulut firewall'ı arkasında çalışır — gelen port gerekmez
  • Alternatif: doğrudan IP ya da tamamen terminal üzerinden kurulum
  • Bulut sunucu tespit edilirse kurulum seni kapalı port tuzağına karşı uyarır

Güvenlik varsayılanı

  • Yalnızca 127.0.0.1'e bind; dışarı açılmak açık tercih
  • Şifre (≥12 karakter) + opsiyonel TOTP 2FA, varsayılan kimlik bilgisi yok
  • Başarısız girişlerde otomatik IP ban, denetim kaydı
  • Kurulan servisler kendi auth'unu kapatır ve loopback'e bind edilir — dışarıya tek kapı Lyra
  • sudoers girdisi yalnızca gereken komutları whitelist'ler, NOPASSWD: ALL yok
  • Dış CDN yok: fontlar ve kütüphaneler pakete gömülü
